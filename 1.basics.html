CSS is used to define styles for your web pages, include the design, layout and variation in display for different devices and screen sizes

Advantages of CSS

  • Saves time (write once and reuse)
  • Easy maintenance (to make a global change, change css code and all are updated)
  • Global web standards (Attributes are deprecated and css is being recommended)
  • Platform independence (script offeres consistent platform independence and can suport latest browsers as well)
