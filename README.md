# CSS Learning Repository for GCE A/L ICT Students (Sri Lanka)

This repository contains **CSS practice files** and exercises designed for GCE Advanced Level (A/L) ICT students in Sri Lanka.  
The purpose of this repository is to provide students with practical examples to learn **CSS structure and basic web development concepts**.

Students can use this repository to:
- Understand the structure of an CSS document
- Practice creating web pages
- Learn CSS selectors, properties, links, images, and borders
- Explore simple styling and layout

---

## Topics covered

- CSS basics
- CSS selectors
- CSS background property
- CSS border property
- CSS font property
- CSS lists
